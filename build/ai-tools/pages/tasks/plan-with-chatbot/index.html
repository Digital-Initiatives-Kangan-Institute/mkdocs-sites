1. Plan a Feature with a Chatbot

1.1 Get Help Designing a Feature

Instructions

Choose a feature you want to add to your cafe website (or any project you are working on). Use a chatbot — ChatGPT, Claude, or Copilot Chat — to help you plan it.

Complete the following steps:

  1. Describe the feature you want to build (e.g. an order form, a contact page, an image gallery)
  2. Ask the chatbot to break it into smaller tasks
  3. Ask for suggestions on what HTML structure, CSS layout, and JavaScript logic you might need
  4. Save the prompts you used and the chatbot's responses in a file called planning.md

Push planning.md to GitHub.

Hint - Click to expand

Start your prompt with context: "I am building a cafe website with HTML, CSS, and JavaScript. I want to add a feature that...". Ask follow-ups if the first response is too vague. The goal is to end up with a clear list of steps you could follow to build the feature.

1.2 Reflect

Instructions

Add a reflection section to your planning.md file covering:

  • What was the most useful part of the chatbot's response?
  • What did you have to ask a follow-up about?
  • Was there anything the chatbot suggested that you would not have thought of on your own?

Push your updated file to GitHub.
