3. Prompt Writing Practice

3.1 Rewrite a Vague Prompt

Instructions

Below are three vague prompts. For each one, write an improved version that is specific, contextual, and structured.

Prompt 1: 

1
Write some HTML for a website.

Prompt 2: 

1
My JavaScript is broken.

Prompt 3: 

1
Make this look better.

For each prompt, write your improved version in a file called prompts.md. Include a brief explanation of what you added and why.

Hint - Click to expand

For Prompt 1: What kind of website? What page? What content? For Prompt 2: What error? What code? What is supposed to happen? For Prompt 3: What element? Better in what way? More spacing? Different colours? Mobile-friendly?

3.2 Test Your Prompts

Instructions

Take your improved versions of the three prompts and try them with a chatbot (ChatGPT, Claude, or Copilot Chat).

For each one:

  1. Paste your improved prompt
  2. Read the response
  3. Ask at least one follow-up question to refine the output
  4. Copy the final exchange into prompts.md under each prompt

3.3 Reflect

Instructions

Add a reflection section to your prompts.md file covering:

  • Which of the three prompts improved the most after rewriting? Why?
  • Did the follow-up question significantly change the response?
  • What is one thing you will do differently when writing prompts going forward?

Push prompts.md to GitHub.
