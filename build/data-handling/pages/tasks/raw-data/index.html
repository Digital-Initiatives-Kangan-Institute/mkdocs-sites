Module 2: Data Profiling Activities

Activity 1: Data Quality Detective

Scenario

You have received a spreadsheet from a local council containing youth survey responses.

Before anyone can analyse the data, it must be profiled and assessed for quality.

Your job is to act as a Data Quality Analyst.

Dataset

Use the workbook:

1
Module2_Activity1_Youth_Survey_Profile.xlsx

Focus on the worksheet:

1
Youth_Survey_Raw

Tasks

Review the dataset and identify examples of:

  • Missing values
  • Duplicate records
  • Inconsistent values
  • Invalid values
  • Mixed data types
  • Potential data entry errors

Complete the Issue Log worksheet in the workbook.

Issue Log Template

Issue Type Example Found Why Is It A Problem?
Missing Value
Duplicate Record
Inconsistent Value
Invalid Value
Mixed Data Type

Discussion Questions

  1. Which issue would be easiest to fix?
  2. Which issue could have the greatest impact on reporting?
  3. Which issues could be solved automatically?
  4. Which issues would require human investigation?

Extension

Rank the issues from:

  • High Risk
  • Medium Risk
  • Low Risk

Justify your decisions.

Learning Outcome

Students should recognise that data profiling helps identify problems before any transformation work begins.

Activity 2: Profile Before You Transform

Scenario

A community engagement team plans to create a dashboard showing youth program participation.

Before building the dashboard, they need to understand the quality of the underlying data.

Dataset

Use the workbook:

1
Module2_Activity2_Youth_Services_Profile.xlsx

Focus on these worksheets:

1
2
Youth_Program_Attendance
Youth_Service_Referrals

Tasks

For each worksheet, answer the following profiling questions.

Worksheet Review Template

Profiling Question Answer
What does each row represent?
What does each column represent?
Are there missing values?
Are there duplicate records?
Are formats consistent?
Are there invalid values?
Is the worksheet analysis-ready?

Group Discussion

Compare findings with another group.

Discuss:

  • Did both groups find the same issues?
  • Were some issues easier to identify than others?
  • Which worksheet would require the most cleaning?
  • Which issues should be fixed before building a dashboard?

Final Task

Create a list of recommended transformations.

Issue Found Recommended Transformation
Example: Attendance values are inconsistent Standardise to Attended / Did Not Attend / Cancelled

Reflection

Answer the following:

If you started transforming this data immediately without profiling it first, what problems might occur later in the project?

Learning Outcome

Students should recognise that:

Data profiling is the process of understanding data before making any changes. A good analyst investigates first, transforms second.
