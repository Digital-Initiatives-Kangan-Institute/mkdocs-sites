1. Initialise and Commit

1.1 Set Up Version Control for a Project

Instructions

Create a new project folder and set up version control from scratch using VS Code.

Complete the following steps:

  1. Create a new folder on your computer and open it in VS Code
  2. Create a simple index.html file with a heading and a paragraph of text
  3. Initialise a Git repository in this folder
  4. Stage and commit your index.html file with a descriptive message

If you have set up GitHub in VS Code, publish the repository.

Hint - Click to expand

Open the Source Control panel with Ctrl+Shift+G or the branch icon in the left sidebar. Click Initialise Repository to start. After creating your file, it will appear under Changes — click the + to stage it, type a message, and click Commit.

1.2 Add a Second Paragraph

Instructions

Add another paragraph of text to your index.html. Stage and commit the change.

1.3 Add a List

Instructions

Add an ordered or unordered list to your index.html. Stage and commit the change.

1.4 Create a Stylesheet

Instructions

Create a new file called styles.css with a few CSS rules (at least three). Stage and commit the change.

1.5 Link the Stylesheet

Instructions

Link the CSS file to your index.html by adding a <link> tag in the <head>. Stage and commit the change.

1.6 Add Navigation

Instructions

Add a navigation section with at least two links to your index.html. Stage and commit the change.

At this point your project should have six commits in its history.

1.7 Check Your Understanding

Instructions

Create a file called answers.md in your project folder and write down your answers to the following questions. Stage, commit, and push it to GitHub.

  • What does staging a file do? Why not just commit directly?
  • What makes a good commit message? Write down three examples of good commit messages from your own commits.
  • How many commits are in your project now? How can you check?
