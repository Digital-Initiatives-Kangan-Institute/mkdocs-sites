3. Daily Workflow

3.1 Add an About Page

Instructions

Complete a full round of the daily workflow by adding a new page to your project.

  1. Create a feature branch called feature/about-page
  2. Create a new file called about.html with a heading and some content about your project
  3. Link to it from your index.html and link back to index.html from about.html
  4. Stage and commit your changes on the branch
  5. Switch to main, Sync to pull the latest from GitHub, then merge feature/about-page
  6. Push to GitHub
  7. Delete the feature branch

3.2 Add a Contact Section

Instructions

Another round — this time add a contact section to your home page.

  1. On main, Sync to get the latest from GitHub
  2. Create a feature branch called feature/contact
  3. Add a contact section to index.html with a heading, some text, and a mailto link
  4. Stage and commit your changes on the branch
  5. Switch to main, Sync, then merge feature/contact
  6. Push to GitHub
  7. Delete the feature branch

3.3 Improve the Look and Feel

Instructions

One more round — improve the visual design of your project.

  1. On main, Sync to get the latest from GitHub
  2. Create a feature branch called feature/design-improvements
  3. Make at least two visual improvements to your styles.css (e.g. change colours, add padding, adjust fonts)
  4. Stage and commit your changes on the branch
  5. Switch to main, Sync, then merge feature/design-improvements
  6. Push to GitHub
  7. Delete the feature branch

3.4 Check Your Understanding

Instructions

Append your answers to the answers.md file in your project. Stage, commit, and push it to GitHub.

  • After completing three full rounds, what is your workflow now? Write down the steps from memory — do not look at the instructions.
  • What would you do if you made a mistake on a feature branch and wanted to start over?
  • Why is it important to push to GitHub at the end of each session?
