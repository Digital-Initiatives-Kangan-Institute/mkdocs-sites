# Additional Resources

Below are additional resources to help you learn **HTML** and **CSS** and build better websites.

---

## Learning HTML and CSS

### W3Schools

**W3Schools** is a popular free website for learning web development, including both **HTML** and **CSS**. It provides simple explanations, interactive examples, and a built-in editor so you can experiment with code in your browser. You can learn how to structure webpages with **HTML** and style them with **CSS** through step-by-step tutorials, making it easy to start building and designing your own websites.

[Click to Visit W3Schools](https://www.w3schools.com/html/default.asp){ .md-button }

### MDN Web Docs

**MDN Web Docs** (by Mozilla) is a detailed reference for every HTML element, attribute and CSS property, with examples and a guide to which browsers support each feature.

[Click to Visit MDN Web Docs](https://developer.mozilla.org/en-US/docs/Learn_web_development){ .md-button }

## Standards and Accessibility

| Resource | Use |
|---|---|
| [W3C Markup Validation Service](https://validator.w3.org/) | Check HTML for errors |
| [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/) | Check CSS for errors |
| [WCAG Quick Reference](https://www.w3.org/WAI/WCAG22/quickref/) | Every WCAG success criterion, with how to meet it |
| [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/) | Check text and background colours meet contrast requirements |
| [OAIC - Australian Privacy Principles](https://www.oaic.gov.au/privacy/australian-privacy-principles) | Official guide to the Privacy Act's principles |
