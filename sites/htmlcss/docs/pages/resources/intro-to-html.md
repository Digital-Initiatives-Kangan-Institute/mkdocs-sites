# Intro to HTML

This site guides you through the basics of how websites are built. You will learn how to plan a website, create simple webpages, style them, link them together into a complete website, test it, and publish it for the world to see.

---

## What is HTML?

**H**yper**T**ext **M**arkup **L**anguage (HTML) is the standard language used to create and structure webpages. HTML tells a web browser what each part of a page is, such as **headings**, **paragraphs**, **images**, and **links**. It uses **tags** to organise content so that it can be displayed correctly on the screen. Without HTML, a webpage would not have any structure or meaning.

HTML is a **markup language**, not a programming language. A markup language labels (or "marks up") content to describe what it is. It does not make decisions or perform calculations.

***

## The Languages of the Web

Most websites are built with three languages that work together. Each one has a different job:

| Language | Full Name | Job | Analogy |
|---|---|---|---|
| **HTML** | HyperText Markup Language | Structure and content: headings, paragraphs, images, links, tables, forms | The frame and walls of a house |
| **CSS** | Cascading Style Sheets | Presentation: colours, fonts, spacing, layout | The paint, carpet and furniture |
| **JavaScript** | JavaScript | Behaviour: interactivity, reacting to clicks, changing the page | The electricity and plumbing |

A **simple website** only needs **HTML** and **CSS**, and those are the two languages this site focuses on.

## Using the Code Editor

Many pages on this site include a live code editor like the one above.

- Type in the **HTML** tab to change the page content
- Type in the **CSS** tab to change how it looks
- The **preview** updates as you type
- Some examples have more than one page. Use the page tabs to switch between them, or click a link in the preview.

Experimenting is the fastest way to learn. You cannot break anything, so change values, delete lines and see what happens.

---

## Summary

- HTML structures the content of a webpage using tags
- CSS controls how the content looks
- A simple website can be built with just HTML and CSS
