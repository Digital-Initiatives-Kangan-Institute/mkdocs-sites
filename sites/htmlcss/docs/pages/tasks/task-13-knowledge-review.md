# Task 13 - Knowledge Review

Answer each question below in your own words. Use the hints to find the resource that covers each topic, but try answering from memory first.

## The Web

!!! abstract "Instructions"
    Answer the following questions:

    - List three applications you could use to access the World Wide Web.
    - Explain the difference between the internet and the World Wide Web.
    - Explain why a website should be tested in more than one browser.
    - Describe what a web server does.
    - Explain what HTTPS is and how you can tell a website is using it.

??? question "Hint"
    All of these are covered in [How the Web Works](../resources/how-the-web-works.md). Think about the engine each browser uses.

## Web Languages

!!! abstract "Instructions"
    Answer the following questions:

    - List and briefly describe the languages used to develop a simple website.
    - Explain the difference between a markup language and the language used for styling.
    - Explain why a website uses one external stylesheet rather than styles on each page.

??? question "Hint"
    See [Intro to HTML](../resources/intro-to-html.md#the-languages-of-the-web) and [Styling with CSS](../resources/css.md#external-stylesheets).

## Development Environments

!!! abstract "Instructions"
    Answer the following questions:

    - Describe the main features of an Integrated Development Environment (IDE).
    - List three things to consider when choosing an IDE for a client.
    - Outline the steps to install the Live Preview extension in VS Code.
    - Explain why file names should be lowercase with no spaces.

??? question "Hint"
    See [Development Environment](../resources/development-environment.md). For each IDE feature, explain how it helps a developer, not just its name.

## Planning

!!! abstract "Instructions"
    Answer the following questions:

    - Describe the purpose of a sitemap.
    - List at least two different types of sitemaps, describe each one, and describe a tool that can be used to create them.
    - Identify the information you should consider when creating a sitemap.
    - Explain why a plan should be confirmed with the client before building starts.

??? question "Hint"
    See [Planning a Website](../resources/planning-a-website.md). Think about who each type of sitemap is made for.

## Standards and Accessibility

!!! abstract "Instructions"
    Answer the following questions:

    - Describe the purpose of the World Wide Web Consortium (W3C).
    - Describe the purpose of the Web Content Accessibility Guidelines (WCAG).
    - List the four principles of WCAG and give an example for each.
    - List five things you can do in HTML and CSS to make a website more accessible.
    - Explain what the W3C validator is used for.

??? question "Hint"
    See [W3C](../resources/w3c.md) and [Accessibility](../resources/accessibility.md). The four principles spell out a short word.

## Publishing
