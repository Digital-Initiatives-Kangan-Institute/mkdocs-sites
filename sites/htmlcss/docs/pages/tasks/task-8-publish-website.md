# Task 8 - Publish Your Website

## Upload Your Site

!!! abstract "Instructions"
    **Using GitHub**, upload the three-page website you built in Task 5 so it is ready to publish.

    Follow the `Creating a GitHub Repository` and `Uploading Site Files` sections of the [Deploying to GitHub Pages](../resources/deployment-github.md) guide. Your repository must contain:

    - `index.html`, `about.html`, and `contact.html` from Task 5

??? question "Hint"
    Your repository needs a `README` file before GitHub will let you upload other files. Double check your file names after uploading — the home page must be called exactly `index.html`.

## Go Live with Pages

!!! abstract "Instructions"
    **Using GitHub**, publish your uploaded site with GitHub Pages.

    Follow the `Deploying to GitHub Pages` and `Viewing your Deployed Website` sections of the guide, then open your live site address in a new browser tab.

??? question "Hint"
    Publishing happens under the repository `Settings` and then the `Pages` section — select the `main` branch and save. The deployment takes a moment: watch the `Actions` tab change from orange to green before opening the link.

## Check Your Live Site

!!! abstract "Instructions"
    **Using your browser**, test your live website the way a visitor would.

    - Visit every page using the navigation menu
    - Confirm your image loads on the home page
    - If you only see your repository name on an otherwise empty page, work through the `Troubleshooting` section of the guide and fix the problem

??? question "Hint"
    Browsers load `index.html` by default when no page is named in the address, so an empty-looking site usually means that file is missing or misnamed. Click every navigation link — a link that goes nowhere usually means its `href` value does not match the real file name.
