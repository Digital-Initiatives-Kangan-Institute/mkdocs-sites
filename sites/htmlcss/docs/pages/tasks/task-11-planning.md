# Task 11 - Planning a Website

!!! note "Working in draw.io"
    Every exercise in this task is done in **draw.io** (`https://app.diagrams.net/`), a free diagramming tool that runs in your web browser.

## Sitemap

!!! abstract "Instructions"
    **Using draw.io**, read the client brief below and create a visual sitemap for the Paws and Claws website.

    - add a box for each page, with its page name and file name
    - connect the boxes with lines to show the hierarchy
    - under each page, add a note listing **every** requirement from the brief that belongs on that page
    - add one more note beside the sitemap for the requirements that apply to **every** page
    - export the finished sitemap as a `PNG` image

    !!! quote "Client brief: Paws and Claws Pet Grooming"
        Hi, I run a small pet grooming salon called Paws and Claws and I'd like our first website. We need four pages: a home page, a services page, an about us page and a contact page.

        The home page should welcome visitors, tell them where we are and when we're open. Please put the opening hours in a table so they're easy to read, and add a link to the services page.

        The services page should list each of our grooming services with a photo, a short description and the price.

        On the about us page I'd like to tell the story of how the salon started and the year we opened, and introduce our groomers with a few words about each of them.

        The contact page needs a form where people can enter their name, email address and a message. It doesn't need to actually send yet, my nephew is going to set that part up later.

        Every page should have a menu so people can get to the other pages, and our logo at the top should take people back to the home page.

??? question "Hint"
    The home page always sits at the top of the sitemap, and its file name is always `index.html`. Every page the client listed sits one level below it.

    Read the brief sentence by sentence, and look out for sentences that contain more than one requirement. The words **"in a table"**, **"with a photo"** and **"every page"** each describe *how* something must be done, and are requirements too.

    The steps to create and export a diagram are in the [Creating a Visual Sitemap with draw.io](../resources/planning-a-website.md#creating-a-visual-sitemap-with-drawio) section of the resource. Connect shapes by dragging from the blue arrows that appear when you hover over a shape.

## Plan the Navigation

!!! abstract "Instructions"
    **Using draw.io**, add the navigation plan to your Paws and Claws sitemap:

    - a box at the top showing the links in the navigation bar, in order
    - an arrow for each link that appears **inside** page content, from the page it is on to the page it goes to
    - an arrow for each image that works as a link

    Export the sitemap as a `PNG` image again.

??? question "Hint"
    The top-level pages in the sitemap become the navigation links. Look back at the brief: the client asked for one link inside the home page content, and one image that works as a link. Use a different line colour or a dashed line for the arrows, so they stand out from the hierarchy lines.

## A Second Brief

!!! abstract "Instructions"
    **Using draw.io**, repeat the two exercises above for a new client: create the sitemap with its requirements, then add the navigation plan.

    !!! quote "Client brief: Riverside Bike Repairs"
        We're a bike repair workshop and we need a simple website. We want a home page, a page listing our repair services, a page selling bike accessories, and a page with our contact details.

        On the home page we want a short introduction, our address and phone number, and our opening hours shown in a table. There should also be a link from the home page to the repairs page.

        The repairs page should have a table of repairs with the price of each one. The accessories page should show each product with a photo, name and price.

        The contact page should have our address and a form with fields for a name, a phone number, an email address, the type of bike and a message.

        Please use our logo on every page and have it link back to the home page, and make sure all the pages have the same menu.

??? question "Hint"
    This brief uses different wording for the same kinds of requirements. Watch for the requirements that are different from the Paws and Claws brief, such as a table on the repairs page and extra form fields on the contact page.

## Check the Sitemap

!!! abstract "Instructions"
    **Using draw.io**, check your Riverside Bike Repairs sitemap and fix it so that:

    - it has a box for every page the client asked for
    - every page can be reached in one click from the home page
    - every file name is lowercase, with hyphens instead of spaces, and ends in `.html`
    - every requirement in the brief appears under the right page

    Then add a `Blog` page to the sitemap, in the place it would fit if the client asked for one later.

??? question "Hint"
    The [What to Consider](../resources/planning-a-website.md#what-to-consider-when-creating-a-sitemap) table in the resource explains each consideration. Read the brief once more, sentence by sentence, and find each requirement on your sitemap.

## Wireframe a Page

!!! abstract "Instructions"
    **Using draw.io**, draw a wireframe of the Paws and Claws **home page**, showing where the logo, navigation, headings, welcome text, address, opening hours table, services link and footer will go.

??? question "Hint"
    A wireframe uses plain boxes and labels, with no colours or real images. Draw a box with a cross through it to show where an image goes, and wavy or straight lines to show text. The **Basic** and **Mockups** shape libraries in draw.io have useful shapes.
